# GodotDialogue Lite 1.0.0

Copy this folder into your Godot 4 project's addons directory. No plugin
activation or autoload is needed. Use GDLiteRunner and instantiate
 dialogue_lite_box.tscn (GDLiteBox); call bind_runner, load_json and start.
See the repository README and demo/sample.json for the API and exact schema.
